# 学生成绩管理系统 - 项目需求文档

## 1. 项目概述
本项目旨在开发一套学生成绩管理系统，支持学校或教育机构对学生信息、考试成绩进行数字化管理，并提供多维度的成绩分析功能，帮助教师和学生及时了解学习情况。

## 2. 功能需求

### 2.1 登录注册功能
- **用户注册**：新用户可通过用户名、密码和身份角色（老师或学生）进行注册，注册后自动激活，无需审核。管理员账号不开放注册，只能通过后端脚本或数据库直接添加。
- **用户登录**：已注册用户通过用户名 + 密码登录，后端验证后返回 JWT token。
- **身份验证与授权**：系统区分管理员、教师、学生三种角色。管理员拥有所有操作权限；教师可管理所教班级的学生信息和成绩；学生仅可查看本人信息及成绩分析。
- **密码加密**：密码采用 bcrypt 或 Argon2 进行哈希存储。

### 2.2 学生信息管理
- **基础信息维护**：增、删、改、查学生基本信息（姓名、学号、性别、出生日期、班级、联系方式等）。
- **Excel 导入导出**：支持通过 Excel 文件批量导入学生信息，并提供模板下载；支持将查询结果导出为 Excel。
- **自定义字段**：允许管理员动态添加自定义字段（如“民族”、“籍贯”、“特长”等），字段类型可包括文本、数字、日期、下拉选项等，灵活扩展而不需修改数据库表结构。
- **信息检索**：支持按学号、姓名、班级等多条件组合查询。

### 2.3 学生成绩管理
- **成绩录入**：支持单条录入和 Excel 批量导入成绩。导入时需验证学号、考试名称、科目等是否存在。
- **成绩维护**：对已录入的成绩进行修改、删除。
- **成绩查询**：按学生、班级、考试、科目等维度查询成绩列表，支持分页和排序。
- **成绩对比展示**：在成绩列表展示时，需对比**本次考试总分**与**上次考试该学生的总分**，计算班级排名和年级排名的升降。用向上绿箭头（↑）表示名次上升，向下红箭头（↓）表示名次下降，并显示升降的具体名次数（例如“↑5”表示班级排名上升5名）。若无上次考试成绩，则对应列显示“-”。
- **成绩导出**：将查询结果导出为 Excel。

### 2.4 学生成绩分析
- **总分历史成绩波动**：针对单个学生，展示其历次考试的总分变化折线图，直观反映整体成绩趋势。
- **单科历史成绩波动**：针对单个学生，可选择某一科目，展示该科目历次考试成绩的变化折线图。
- **名次变化**：展示学生在班级或年级中的名次变化曲线（需基于每次考试的全班/全年级成绩排名计算）。
- **优劣势学科分析**：通过雷达图或柱状图对比学生各科成绩与班级平均分、年级平均分，识别优势与薄弱学科。

### 2.5 班级成绩分析
- **班级排名**：支持按总分平均分对各班级进行排名，也可按各科目平均分进行排名。
- **成绩分布分析**：针对单个班级，分析其总分及各科的优秀率、良好率、合格率，并以饼图或柱状图展示。
  - 优秀率：分数 ≥ 90 分（或自定义阈值）的人数占比。
  - 良好率：分数 ≥ 80 分且 < 90 分的人数占比。
  - 合格率：分数 ≥ 60 分的人数占比。
- **后进生分析**：对班级总分排名靠后的学生，分析其各科成绩，找出薄弱科目，为针对性辅导提供依据。
- **偏科生统计分析**：识别班级中偏科严重的学生。偏科定义：学生个人各科成绩的标准差大于班级平均标准差的一定倍数，或单科成绩与自身平均分差距过大。系统需列出偏科生名单，并突出显示其弱势科目。

## 3. 非功能需求

- **性能**：页面响应时间 < 2秒，API 响应时间 < 500ms（不含复杂分析），支持并发用户数 ≥ 100。
- **安全性**：用户密码加密存储；API 需进行身份验证，防止未授权访问；文件上传需校验类型和大小，防止恶意文件。
- **可扩展性**：自定义字段功能应易于扩展，无需修改核心代码即可添加新字段。
- **易用性**：UI 符合 Ant Design 风格，操作流程直观，提供必要的提示和错误反馈。
- **可维护性**：代码结构清晰，遵循 PEP8 和 ESLint 规范，提供 API 文档和必要的注释。
