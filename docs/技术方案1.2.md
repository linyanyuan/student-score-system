# 学生成绩管理系统 - 技术方案

## 1. 总体架构
系统采用前后端分离架构：
- **前端**：React 单页应用，通过 Axios 调用后端 API。
- **后端**：FastAPI 应用，处理业务逻辑与数据持久化。
- **数据库**：SQLite（轻量级文件数据库，适合中小规模部署）。
- **部署**：可使用 Docker 容器化部署，前端静态文件由 Nginx 托管，后端使用 Uvicorn + Gunicorn 运行。

## 2. 前端技术栈
- **框架**：React 18
- **UI 组件库**：Ant Design 5.x
- **状态管理**：React Context / Redux Toolkit（根据复杂度选择）
- **路由**：React Router 6
- **HTTP 客户端**：Axios
- **表格与图表**：Ant Design Table + ECharts（或 Ant Design Charts）
- **Excel 处理**：使用 `xlsx` 库在前端解析/生成 Excel（或交由后端处理）
- **构建工具**：Vite 或 Create React App

## 3. 后端技术栈
- **Web 框架**：FastAPI
- **ORM**：SQLAlchemy 2.0 + Alembic（用于迁移）
- **数据验证**：Pydantic
- **认证授权**：python-jose（JWT） + passlib（bcrypt）
- **Excel 处理**：pandas 或 openpyxl
- **文件上传**：python-multipart
- **CORS**：fastapi.middleware.cors
- **数据库驱动**：sqlite3（Python 内置，或使用 aiosqlite 实现异步）

| is_active    | boolean     | 是否激活（始终为 true，保留字段） |

| class_id     | integer     | 班级 ID（外键）          |

**4. 考试表 (exams)**
| 字段名       | 类型        | 说明                     |

| 字段名       | 类型        | 说明                     |
|--------------|-------------|--------------------------|

**6. 成绩表 (scores)**
| 字段名       | 类型        | 说明                     |
|--------------|-------------|--------------------------|

| created_at   | timestamp   | 创建时间                 |

**7. 总分排名表 (total_ranks)** （新增，用于存储每次考试每个学生的总分及排名）
| 字段名       | 类型        | 说明                     |
|--------------|-------------|--------------------------|
| id           | integer     | 主键，自增               |
| student_id   | integer     | 学生 ID（外键）          |
| exam_id      | integer     | 考试 ID（外键）          |
| total_score  | float       | 总分（各科成绩汇总）     |

| rank_grade   | integer     | 年级排名                 |
| created_at   | timestamp   | 创建时间                 |

- 成绩表联合唯一约束：(student_id, exam_id, subject_id)
- 总分排名表联合唯一约束：(student_id, exam_id)
- 所有表主键均使用 `INTEGER PRIMARY KEY AUTOINCREMENT`

## 5. 接口设计（RESTful API）

### 认证模块
- `POST /api/auth/register` - 用户注册（仅限教师、学生角色，注册后自动激活）
- `POST /api/auth/login` - 登录，返回 access_token
- `GET /api/auth/me` - 获取当前用户信息

### 学生信息管理
- `GET /api/students` - 分页查询学生列表（支持姓名、学号、班级过滤）
- `GET /api/students/{id}` - 获取单个学生详情
- `POST /api/students` - 新增学生
- `PUT /api/students/{id}` - 修改学生信息
- `DELETE /api/students/{id}` - 删除学生
- `POST /api/students/import` - 导入 Excel 学生数据
- `GET /api/students/export` - 导出学生数据（Excel）
- `GET /api/students/template` - 下载导入模板

### 成绩管理
- `GET /api/scores` - 分页查询成绩列表，返回数据包含：
  - 当前成绩信息（各科成绩）
  - 本次考试该学生的总分、班级排名、年级排名（从 `total_ranks` 获取）
  - 上次考试该学生的总分、班级排名、年级排名
  - 班级排名升降（↑5 / ↓3 / -）
  - 年级排名升降（↑5 / ↓3 / -）
- `POST /api/scores` - 录入单条成绩（同时触发总分和排名计算）
- `PUT /api/scores/{id}` - 修改成绩（同时触发总分和排名计算）
- `DELETE /api/scores/{id}` - 删除成绩（同时触发总分和排名计算）
- `POST /api/scores/import` - 导入 Excel 成绩（批量处理并计算总分排名）
- `GET /api/scores/export` - 导出成绩（Excel）
- `GET /api/scores/template` - 下载成绩导入模板

### 学生成绩分析
- `GET /api/analysis/student/{student_id}/total-trend` - 获取学生总分历次考试趋势
- `GET /api/analysis/student/{student_id}/subject-trend/{subject_id}` - 获取学生某科目历次考试趋势
- `GET /api/analysis/student/{student_id}/rank-trend` - 获取学生历次考试名次变化
- `GET /api/analysis/student/{student_id}/subject-comparison` - 获取学生各科成绩与班级/年级平均分对比

### 班级成绩分析
- `GET /api/analysis/classes/rank` - 班级排名（按总分平均分或指定科目平均分）
- `GET /api/analysis/class/{class_id}/exam/{exam_id}/distribution` - 获取班级某次考试的成绩分布（优秀率、良好率、合格率）
- `GET /api/analysis/class/{class_id}/exam/{exam_id}/bottom-students` - 获取班级总分排名靠后的学生及其各科成绩详情
- `GET /api/analysis/class/{class_id}/exam/{exam_id}/biased-students` - 获取班级中的偏科生列表
  - 参数：可选阈值（如标准差倍数）
  - 返回：偏科生名单，包含学生信息、各科成绩、偏科科目提示

### 辅助接口
- `GET /api/classes` - 班级列表
- `GET /api/exams` - 考试列表
- `GET /api/subjects` - 科目列表

## 6. 关键实现细节

### 6.1 自定义字段实现
- 学生表使用 JSON 字符串存储自定义字段，后端读写时进行序列化/反序列化。

### 6.2 总分排名与升降计算
- **总分计算与排名存储**：每次成绩录入、修改或删除后，触发异步任务或同步计算该次考试所有学生的总分，并更新 `total_ranks` 表。计算班级排名和年级排名时，需按班级和年级分别排序。
- **上次排名获取**：在查询成绩列表时，对于每个学生，从 `total_ranks` 表中找到当前考试记录，并找到该学生上一次考试（按考试日期早于当前考试且最接近的）的记录，取出其班级排名和年级排名。
- **升降标识**：比较当前排名与上次排名，计算差值。若上升（排名数字变小），返回字符串如 `"↑5"`；若下降，返回 `"↓3"`；若无上次记录，返回 `"-"`。
- **前端渲染**：根据返回的升降字符串，用绿色显示上升箭头，红色显示下降箭头。

### 6.3 偏科生分析算法
- **定义**：对于一次考试，计算班级内每个学生所有科目的标准差，再计算班级平均标准差。若某学生标准差 > 班级平均标准差 * K（K 可配置，默认 1.5），则视为偏科生。
- **实现**：在后端接口中，查询指定班级和考试的所有成绩，按学生分组计算各科成绩的标准差，与班级整体标准差比较，筛选出偏科生名单。同时找出该生最低分科目作为弱势科目提示。

### 6.4 Excel 导入导出
- 使用 pandas 处理 Excel，导入时进行数据校验和事务处理。

### 6.5 安全性
- JWT 认证，密码哈希，文件上传限制。

## 7. 开发与部署建议

- **开发环境**：
  - 前端：`npm start`，代理后端 API。
  - 后端：`uvicorn main:app --reload`，配置 CORS。
  - SQLite 数据库文件可放在项目目录。
- **数据库迁移**：Alembic 管理。
- **测试**：pytest 编写单元测试和 API 测试。
- **部署**：前端构建后 Nginx 托管，后端 Gunicorn+Uvicorn，可使用 Docker Compose。
