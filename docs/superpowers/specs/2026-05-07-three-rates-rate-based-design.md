# 三率一分率口径调整设计

## 背景

班级成绩分析的“三率一分排名”原先用各班达标人数与同组最高达标人数归一化。新口径要求先计算本班达标率，再与同组最高达标率归一化，并新增低分率得分。

## 计算口径

- 分母使用同一次考试批量导入成绩表中该班级对应的人数，即该考试下该班出现过的学生去重数。
- 优秀率 = 本班优秀人数 / 本班导入人数，优秀为成绩 >= 满分 * 0.8。
- 良好率 = 本班良好人数 / 本班导入人数，良好为成绩 >= 满分 * 0.7。
- 及格率 = 本班及格人数 / 本班导入人数，及格为成绩 >= 满分 * 0.6。
- 低分率 = 本班低分人数 / 本班导入人数，低分为成绩 <= 满分 * 0.3。
- 优秀率分数、良好率分数、及格率分数分别用本班对应率除以同组最高对应率后乘以 100。
- 低分率得分按低分率从低到高排名，最低为 100 分，之后每降一名少 2 分；低分率相同按并列名次给相同分数。
- 总分数 = 优秀率分数 + 良好率分数 + 及格率分数 + 低分率得分 + 平均分。

## 范围

- 后端保持现有同组范围：同学校、同年级内比较。
- 前端在“三率一分排名”表格新增“低分率得分”列。
- 不改成绩分布模块的区间统计口径。

## 验证

- 后端纯函数单测覆盖率口径、满分阈值、低分率排名和并列。
- 前端静态内容测试覆盖新增列。
- 运行相关后端 unittest 与前端页面内容测试。
