# 成绩年级导入与权限调整设计

## 背景与目标
- 支持 `school_admin` 和 `teacher` 对“某年级全量学生成绩”进行一键 Excel 导入。
- 导入时必须选择导入年级，并且该年级必须属于当前考试参与年级。
- Excel 字段采用常见别名自动识别，兼容不同来源模板。
- 修复教师导入后列表不可见问题：教师可查看“当前考试年级”下全部班级成绩。

## 关键规则
1. 导入接口新增必填参数 `grade`。
2. `grade` 与考试参与年级不一致时，直接拒绝导入。
3. 行级校验学生归属年级（由学生 `class_id -> Class.grade` 推导），不匹配则该行失败。
4. 查看范围：
- `teacher` 在成绩列表中可查看当前考试年级下全部班级成绩。
- `school_admin`、`admin` 维持现有全校/全局逻辑。
- `student` 仍只看本人。

## Excel 自动识别
### 固定字段别名
- 学号：`学号`、`学生学号`、`学籍号`
- 姓名：`姓名`、`学生姓名`
- 班级：`班级`、`班级名称`
- 总分：`总分`、`总成绩`（可选列）
- 班级排名：`班级排名`、`总分班名`
- 年级排名：`年级排名`、`总分总名`

### 科目别名（示例）
- 道法：`道法`、`政治`、`道法(政治)`、`思想品德`
- 其他科目按去空格、全角半角括号归一后匹配。

## 影响模块
- 后端：
  - `backend/app/routers/scores.py`
  - `backend/app/routers/analysis.py`（同步教师年级可见策略，避免模块行为不一致）
- 前端：
  - `frontend/src/api/score.js`
  - `frontend/src/pages/ScoreManage.jsx`

## 风险与兼容
- 旧导入流程需新增 `grade` 参数，前端必须同步改造。
- 年级可见性放开后，教师在成绩模块可见数据量会增加，分页查询必须保持。
